# Phase 2 — Bibliothèque, exercices, séances : plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** livrer la phase 2 en 5 morceaux testés et mis en ligne.
**Architecture:** logique pure dans `src/modele/` (testée), stockage par collection dans `src/stockage.ts`, écrans dans `src/ui/`. L'animation est extraite dans un hook `useLecture` partagé par l'éditeur et la présentation.
**Tech Stack:** inchangée + jsPDF (2e, import dynamique, précaché).
**Spec:** `docs/superpowers/specs/2026-10-19-triple-threat-design.md` (section Phase 2)

## Global Constraints
- Rien chargé d'internet ; tout précaché. Interface en français. Cibles tactiles ≥ 48 px.
- Les données existantes (version 1) restent lisibles : conversion à la lecture et à l'import.

## Review Focus
1. Données version 1 déjà sur l'iPad → converties sans perte (`documents.test.ts`).
2. Passe d'un joueur sans ballon, plusieurs ballons, relais → ballons finaux et animation corrects (`etapes.test.ts`, `animation.test.ts`).
3. Import d'un fichier avec séances dont les documents arrivent en copie → les blocs pointent vers les copies (`fichier.test.ts`).
4. Recherche avec ou sans accents → mêmes résultats (`documents.test.ts`).
5. Séance qui contient un document supprimé → ignoré en présentation, signalé dans la liste.
